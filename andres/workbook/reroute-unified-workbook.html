Unified data model

Click an entity for fields. Types live in schemas/unified-cdm.types.ts.

Verdict names: use ALLOWED | NEEDS_REVIEW | BLOCKED. CLEAR’s CLEARED/REVIEW/BLOCKED map at the UI edge only.

Composition rule

final = worst(packDecisions)
  BLOCKED > NEEDS_REVIEW > ALLOWED

Each Alternative gets its own Decision before substitution.
Post-FFmpeg Version is fully re-evaluated.

A — P0 demo (SAS sponsored FR IG)

  1. Open 15s edit (3 segments) from ScorePlay
  2. Dial: FR · Instagram · sponsored · DEMO campaign
  3. Check → BLOCKED on 00:04–00:09
  4. Evidence → DEMO advertiser rule + TL brand observation
  5. Find path → similar dunk → independent rights check
  6. REROUTE + FFmpeg → re-check whole edit → ALLOWED
  7. Rights Receipt → optional ScorePlay writeback

B — Policy Dial flip

  1. Same pixels, usage=organic → softer / allow
  2. Flip to sponsored → verdict changes (jury WOW setup)

C — Multi-holder (Tottenham / NFL venue)

  1. NFL marks without entitlement → NEEDS_REVIEW
  2. Search venue-only cleared alternatives · never invent permission

D — CLEAR creator → producer library

  1. Attest ownership · scoped micro-license · consent event
  2. Signals (music/minor) → REVIEW/BLOCKED fail-safe
  3. CLEARED asset becomes Media + EntitlementFacts for REROUTE

E — No compliant path

  1. Alternatives all fail packs → stay BLOCKED / NEEDS_REVIEW
  2. Still emit Receipt documenting the attempt

System workflows

W1 · Ingest & observe

SP search/GET → map CDM → TL method=url → ObservationRun (or cache)

W2 · Evaluate

Intent + Edit + Observations + Entitlements + Packs → Decision

W3 · Reroute

Marengo search → Alternatives → filter by W2 → FFmpeg → re-W2

W4 · Receipt & writeback

RightsReceipt JSON → SP tags if permitted → human approve

W2 evaluate (detail)

for each Segment:
  observations = TL facts in [start, end]
  facts = EntitlementFacts for asset
  packs = resolve(league, team, player, territory, advertiser, …)
  packDecisions[] = evaluate(intent, observations, facts, pack)
segmentVerdict = worst(packDecisions)
editVerdict = worst(segmentVerdicts)
